Andrew's Markup Privacy Policy

Effective August 2, 2026

Andrew's Markup is a browser extension for annotating the current web page and capturing the annotated result. It has no accounts, advertising, analytics, or tracking.

Information the extension handles

When you activate the extension, it handles the current page's visible content so it can display annotations and create the screenshot you request. It also handles your drawing input, clicks, pointer positions, and scrolling while annotation mode is active. This information is used only to provide the annotation and capture features.

Local processing and retention

Page content, annotations, and captures are processed locally in your browser. They are not transmitted to the developer or any third party. Annotations remain in memory only for the current annotation session. A completed capture is placed on your device's clipboard at your request. The extension stores only your hand-drawn style preference in Chrome's local extension storage, where it remains until you change it or remove the extension.

Permissions

  • activeTab provides temporary access to the current page only after you invoke the extension.
  • scripting displays the annotation toolbar and canvas on that page.
  • storage remembers the hand-drawn style preference locally.

Sharing and sale

The extension does not sell, transfer, or share user data. It does not use data for advertising, creditworthiness, or any purpose unrelated to annotating and capturing the page.

Limited Use

The use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Changes and contact

This policy will be updated if the extension's data practices change. Questions can be submitted through the project's GitHub issue tracker.
